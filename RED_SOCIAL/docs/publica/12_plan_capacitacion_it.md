# 12. Plan de capacitaciones para el equipo de IT

| Módulo | Contenido | Duración | Material |
|---|---|---|---|
| 1. Arquitectura de la aplicación | Capas, flujo de subida, decisiones de diseño | 2 h | `docs/publica/01`, `02` |
| 2. Desarrollo local | Clonar, `.env`, migraciones, correr y probar | 2 h | `README.md`, manual 10 |
| 3. Flujo con Git | Ramas por persona, Pull Requests, commits | 1 h | `CONTRIBUTING.md` |
| 4. AWS esencial | EC2, S3, IAM Roles, Security Groups, Route 53 | 3 h | `infra/`, manuales 4 y 9 |
| 5. Despliegue y operación | `deploy.sh`, logs, reinicios, suspender la EC2 | 2 h | `instrucciones_despliegue.md` |
| 6. Seguridad | Gestión de secretos, rotación de claves, auditoría | 2 h | manuales 3 y 6 |
| 7. Base de datos | Prisma, migraciones, respaldos y restauración | 2 h | manuales 7 y 11 |
| 8. Procesamiento de imágenes | sharp, agregar una transformación | 1.5 h | `CONTRIBUTING.md` |

**Evaluación:** cada participante despliega la aplicación en una instancia de prueba y restaura un respaldo.
